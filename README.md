# N1TA-MOF-LOF
A redesign and update of the <a href="https://wiki.k1ttt.net">K1TTT MOF/LOF program</a>. 

Although probably superseded by better prediction software, some of which is free for use online, this desktop application might be useful in situations without internet access. Don't expect much support, but feel free to ask. 

Credit to Dave, K1TTT for his original program.
